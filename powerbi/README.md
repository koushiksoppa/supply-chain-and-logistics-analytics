# Power BI Dashboard Materials

This folder has everything needed to build the dashboard in Power BI Desktop:

- `data/` — 6 CSVs ready for direct import (`fact_orders.csv` + 5 dimension tables including a proper `dim_date.csv`)
- `DAX_measures.md` — every KPI as a copy-pasteable DAX measure
- `DASHBOARD_BUILD_GUIDE.md` — page-by-page build instructions for all 6 dashboard pages, mapped to every required visual type
- `supply_chain_dashboard.pbix` — (add this once you've built it locally; Power BI Desktop isn't available in this environment, so the .pbix itself has to be built on your machine using the materials above)

Start with `DASHBOARD_BUILD_GUIDE.md` Section 1 (Setup).
